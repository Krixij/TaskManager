## Установка проекта TaskManager

### 1. Клонируйте репозиторий:

git clone https://github.com/Krixij/TaskManager.git
#### cd TaskManager

### 2. Создайте виртуальное окружение:
(Если команда python не работает, попробуйте py или python3)
#### python -m venv .venv
#### .venv\Scripts\activate

### 3. Установите зависимости (библиотеки):
#### pip install -r requirements.txt

### 4. Примените миграции базы данных:
#### python manage.py migrate

При обновлении проекта с новыми полями эту команду нужно выполнять, чтобы обновить структуру SQLite.

### 5. Запустите сервер:
#### python manage.py runserver

### 6. Проверка, что всё работает:
После запуска сервера откройте в браузере:
#### http://127.0.0.1:8000/

Должна открыться страница входа в TaskManager.

### Важно!
#### База данных находится в файле db.sqlite3. Перед изменениями рекомендуется сделать его резервную копию.
#### После получения обновлений с новыми полями запускайте python manage.py migrate.
#### Виртуальное окружение должно быть активировано — в начале строки терминала должно быть (.venv)

### Обновление кода:
#### git pull
